# Jamaat Ilaqa Android App

Official Android application for the Jamaat e Islami Reporting System.

This repository is dedicated to distributing official Android APK releases of the Jamaat e Islami Reporting System.

## Download the App

Visit the [Latest Release](https://github.com/clinickhalideye/Jamaat-Ilaqa-Android/releases/latest) to download and install the latest Android APK.

## Features

- Daily Activity Reporting
- Monthly Reports
- Other Activity Reporting
- Suggestions, Complaints and Advice
- Members Management
- Progress and Charts
- Offline Entry Support
- Automatic Data Synchronization
- Notifications

## Installation

1. Open the Latest Release page.
2. Download the APK file.
3. Open the downloaded APK on your Android device.
4. Allow installation from unknown sources if requested.
5. Install and sign in using your authorized account.

## Important

- This application is intended for authorized Jamaat e Islami office-bearers.
- User accounts are created by the responsible administrators.
- Public registration is not available.
- An active internet connection is required for online synchronization.
